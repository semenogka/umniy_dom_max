Почему масштабирование дешёвое: УК не нужно внедрять новое ПО и обучать людей — обращения приходят на обычную почту. Это важно для регионов, где не хватает цифровых кадров. Для роста API нужен общий брокер WebSocket-комнат вместо памяти одного процесса.
